__init__(filename, compute_site=None, shell=None, dependencies=None, permissions=None)[source]#

A class for programmatically creating batch/script files. The behavior of the batch file can be customized by specifying the compute site and shell to use.

Parameters:

  • filename (str | Path) – The name of the batch file. The file extension will be automatically set based on the Shell.

  • compute_site (ComputeSiteType) – The ComputeSite where the batch file will be executed.

  • shell (ShellType) – The Shell that will be used to execute the batch file.

  • dependencies (str | DependencySettings | Iterable[str | DependencySettings]) – A list of dependencies that are required by this batch file.

  • permissions (str | FilePermissions) – The file permissions for the batch file in octal format (e.g., ‘700’).

Raises:

  • TypeError – If compute_site or shell are of incorrect types.

  • ValueError – If permissions do not allow owner execute access.

classmethod from_config(config, context=None)[source]#

Create a pre-configured BatchFile instance from a BatchJobConfig. If the config includes an appropriate template, the batch file contents will be populated and any placeholder variables will be replaced using the provided context.

Placeholder variables in the template should be in the format __VAR__, where VAR corresponds to a key in the context dictionary.

Parameters:

  • config (BatchJobConfig | dict) – A BatchJobConfig instance or dictionary.

  • context (dict) – A dictionary of context variables for rendering the template.

Returns:

A BatchFile instance configured according to the provided config.

class xtl.jobs.batchfiles.BatchFileStatus[source]#

Bases: StrEnum

Enumeration of possible statuses for a BatchFile.

CANCELLED = 'cancelled'#

The batch file execution has been cancelled.

COMPLETED = 'completed'#

The batch file has completed execution successfully.

FAILED = 'failed'#

The batch file execution has failed.

IDLE = 'idle'#

The batch file has been instantiated. It may not be saved to disk yet.

RUNNING = 'running'#

The batch file is currently being executed on a compute site.

SCHEDULED = 'scheduled'#

The batch file has been scheduled for execution on a compute site.
