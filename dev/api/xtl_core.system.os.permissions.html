xtl_core.system.os.permissions module#

POSIX file permissions: parsing, conversion between their forms, and changing them recursively.

class xtl_core.system.os.permissions.FilePermissions[source]#

Bases: object

Representation of POSIX file permissions for owner, group, and other.

Created from the three parts, each as for FilePermissionsBit (e.g. FilePermissions(7, 'r-x', 0)), or from a single value for all of them: an int (0o750), three octal digits ('750', '0750' or '0o750'), canonical letters with or without the file type ('rwxr-x---', 'drwxr-x---') or another FilePermissions. A single value that is none of these is the owner’s part ('rwx' is 0o700). The parts are always copies: changing a FilePermissionsBit passed in doesn’t change the permissions.

xtl_core.system.os.permissions.chmod_recursively(path, files_permissions=None, directories_permissions=None)[source]#

Change the permissions of a directory and of all files and subdirectories within it, or of a single file. Symbolic links are skipped, and never followed.

Parameters:

  • path (str | Path) – The path to the directory or file

  • files_permissions (int | str | FilePermissions | None) – The desired permissions for files; None leaves them unchanged

  • directories_permissions (int | str | FilePermissions | None) – The desired permissions for directories; None leaves them unchanged

Raises:

  • ValueError – If neither permissions are given, or one isn’t valid.

  • FileNotFoundError – If the path doesn’t exist.

  • OSError – If a permission can’t be changed, or a directory can’t be listed.
