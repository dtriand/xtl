xtl.jobs.ipc.base.NOT_YET = NOT_YET#

What an attempt passed to poll() returns when it should be retried.

xtl.jobs.ipc.base.POLL_FIRST = 0.001#

Seconds before the first retry of poll().

xtl.jobs.ipc.base.POLL_MAX = 0.05#

Longest time between two retries of poll().

async xtl.jobs.ipc.base.poll(attempt)[source]#

Wait for a thread or process primitive without blocking the event loop: call attempt until it returns something other than NOT_YET, sleeping between tries, twice as long each time up to POLL_MAX.

Unlike waiting in an executor thread, which can’t be stopped, a cancelled or timed-out wait leaves nothing behind: no thread that later takes the lock or an item, and nothing for asyncio.run() to wait for on exit.

Parameters:

attempt (Callable[[], Any]) – A non-blocking try, e.g. lock.acquire(blocking=False) or queue.get_nowait(); it may return an awaitable of its result instead.

Returns:

What the successful attempt returned.

Any
