xtl.jobs.ipc.processes.ignore_interrupts()[source]#

Make the current process ignore Ctrl+C (SIGINT), for the processes of a pool: Ctrl+C reaches every process on the console, and is the parent’s to handle. On POSIX with a handler that does nothing rather than SIG_IGN, which programs started from the process would inherit (it isn’t reset on exec), so that a batch file’s programs still stop on SIGINT; on Windows with SIG_IGN, since a handler would still interrupt the process’s waits.

Return type:

None

xtl.jobs.ipc.processes.shielded_context()[source]#

A multiprocessing context for the processes of a pool (its workers and its manager), with the default start method, whose processes ignore Ctrl+C from their start; their initializer must call ignore_interrupts().

Return type:

BaseContext
