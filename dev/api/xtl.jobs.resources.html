class xtl.jobs.resources.ResourceManager[source]#

Bases: object

Manages a global pool of resources and grants leases to requesters. Supports hierarchical resource management through nested leases. Each ResourceManager is intended to be used within a single event loop to avoid sharing asyncio primitives across loops.

Parameters:

total – The total resources available for allocation. Each field will be clamped to a minimum of 1.

class xtl.jobs.resources.ResourcesLease[source]#

Bases: object

Represents a lease of resources granted by a ResourceManager. Supports nested leases for hierarchical resource management.

A lease may be released while its children are still open (e.g. a pool exits while one of its jobs still runs a pool of its own): it then gives back only what its children don’t hold, and its children belong to its parent (or the manager) from then on, so that the manager never hands out more than its total.

Parameters:

  • manager – The ResourceManager that granted this lease.

  • granted – The Resources that were granted for this lease.

  • token – The ContextVar token for this lease, used to restore previous lease scope on release.

  • parent – The parent ResourcesLease if this is a nested lease, or None if this is a root lease.

async acquire_child(requested, timeout=None)[source]#

Acquire a child lease from this current lease. The requested resources will be capped to the granted resources of this lease.

Parameters:

  • requested (Resources) – The resources being requested for the child lease.

  • timeout (float | None) – Optional timeout in seconds for acquiring the child lease. If None, wait indefinitely.

Returns:

A ResourcesLease representing the granted child resources. If this lease is released, before or while waiting, the request goes to its nearest open parent, or to the manager.

Return type:

ResourcesLease

async release()[source]#

Release this lease: give back to the parent lease, or the manager, what isn’t held by open child leases, which from then on belong to the parent, or the manager, and give theirs back when they are released. The lease in scope goes back to what it was before this lease.

Return type:

None
