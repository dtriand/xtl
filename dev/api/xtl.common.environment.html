xtl.common.environment module#

Central location for environment variables and related utilities.

class xtl.common.environment.EnvVar[source]#

Bases: Generic[T]

An environment variable that is read on every access, so that changes to the environment are reflected immediately. Empty values are treated as unset.

xtl.common.environment.XTL_COMPUTE_SITE: EnvVar[str] = EnvVar(name='XTL_COMPUTE_SITE', parser=<class 'str'>, default=None)#

Enables compute sites (see xtl.jobs.sites.ComputeSite) for specific facilities. Read when xtl.jobs.sites is imported. Currently supported values are:

  • BIOTIX_HPC enables biotix

xtl.common.environment.XTL_CONFIG: EnvVar[Path] = EnvVar(name='XTL_CONFIG', parser=<function _normalize_path>, default=None)#

Path to the config file, which takes precedence over all other config file locations (see XTLSettings.locations()).

xtl.common.environment.XTL_FONTS_DIR: EnvVar[Path] = EnvVar(name='XTL_FONTS_DIR', parser=<function _normalize_path>, default=None)#

Directory with additional fonts for plots. Reserved for the plotting backends, which are still in development; it has no effect yet.
