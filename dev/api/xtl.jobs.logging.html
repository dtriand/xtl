class xtl.jobs.logging.JobNameFilter[source]#

Bases: Filter

Sets record.job, the name of the record’s logger as shown on screen, relative to a base logger:

  • the base’s own records get its label, e.g. MultiprocessPool;

  • records from below it get their name relative to it, with each nested pool hidden and shown as a > instead, e.g. Talker|01.2 or Outer|01>Talker|03; a nested pool’s own records end in its label;

  • records from loggers outside it keep their full name.

The filter lets every record through.

configure(logger, label=None)[source]#

Configure the given logger based on this configuration. Handlers built from configs are tagged with a _xtl_owned attribute, and live handlers with _xtl_live; both are replaced on consecutive calls of this method (only the former are closed). Other handlers are not modified. Each installed handler gets a JobNameFilter, unless it has one already, so that formats can use %(job)s.

Parameters:

  • logger (Logger) – The logger to configure

  • label (str | None) – Optional, how the logger’s own records are named on screen, e.g. a pool’s label. If not provided, records are named relative to the logger’s parent, which suits jobs.

class xtl.jobs.logging.RelayHandler[source]#

Bases: QueueHandler

The sink of a worker process: puts every record on a queue as a JSON-safe dict (record_to_dict()), for the parent to re-emit.

prepare(record)[source]#

Prepare a record for queuing. The object returned by this method is enqueued.

The base implementation formats the record to merge the message and arguments, and removes unpickleable items from the record in-place. Specifically, it overwrites the record’s msg and message attributes with the merged message (obtained by calling the handler’s format method), and sets the args, exc_info and exc_text attributes to None.

You might want to override this method if you want to convert the record to a dict or JSON string, or send a modified copy of the record while leaving the original intact.

Parameters:

record (LogRecord)

Return type:

dict[str, Any]

static record_to_dict(record)[source]#

Convert a log record to a JSON-safe dict, for the parent process to re-emit (xtl.jobs.pools.MultiprocessPool._relay_log()). The message is formatted with its arguments, the traceback is kept as text, and any other value that JSON can’t hold is turned into a string.

Parameters:

record (LogRecord) – The record to convert.

Returns:

A dict that logging.makeLogRecord() turns back into a record.

Return type:

dict[str, Any]
