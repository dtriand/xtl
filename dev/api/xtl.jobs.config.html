get_batch(context=None, dependencies=None, compute_site=None, shell=None)[source]#

A batch file for this configuration, with the template of its shell rendered.

Parameters:

  • context (dict) – Optional dictionary of additional context variables to be used when rendering the batch file template.

  • dependencies (Iterable[DependencySettings | str] | None) – Names or settings of the job’s dependencies, set up and guarded in the preamble.

  • compute_site (Optional[ComputeSiteType]) – The compute site, if already chosen; otherwise chosen with the shell (see select_site_and_shell()).

  • shell (Optional[ShellType]) – The shell, if already chosen (together with compute_site).

Return type:

select_site_and_shell(dependencies=None)[source]#

The compute site and shell that run this batch job, from the configuration (compute_site, default_shell, the shells of the templates) and the job’s dependencies (see select_site_and_shell()).

Parameters:

dependencies (Iterable[DependencySettings | str] | None) – Names or settings of the job’s dependencies.

Raises:

  • DependencyError – If the dependencies ask for different compute sites, shells or policies.

  • ValueError – If the shell asked for isn’t one that the site and the templates allow.

Return type:

tuple[ComputeSiteType, ShellType]
