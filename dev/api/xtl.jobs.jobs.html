class xtl.jobs.jobs.BatchJob[source]#

Bases: Job[BatchJobConfig], Generic[BatchJobConfigType]

This is a concrete implementation of Job for executing batch files. Batch files can be customized based on the underlying operating system and get dynamically rendered using the provided BatchJobConfig and context.

__init__(*args, **kwargs)[source]#

Abstract base class for asynchronous jobs execution.

Parameters:

  • config – Optional, the configuration of the job, an instance of the job’s configuration class (see configure()). A job without one can be configured later.

  • job_id – Optional, an identifier for the job, used as given; it must be usable in file names and commands (no | / \ : * ? " < >). If not provided, a random ID is generated. A pool makes sure its jobs’ IDs are unique; two jobs given the same ID outside a pool share a logger.

  • logger – Optional, a custom logger for the job. If not provided, a logger will be created using the job’s label and logger_config.

  • logger_config – Optional, the logging configuration of the job, also passed on to its child jobs. If not provided, the default of this job type is used.

Raises:

ValueError – If job_id isn’t usable in file names and commands (see check_job_id()).

class xtl.jobs.jobs.SteppedJob[source]#

Bases: Job[SteppedJobConfig], Generic[JobConfigType]

This is a concrete implementation of a Job with multiple sequential steps. Any subclasses need to define their own _steps class variable with a set of ``StepSpec``s that specify the list of steps. Any other Job can be used as a step, including BatchJob and SteppedJob.

  • logger – Optional, a custom logger for the job. If not provided, a logger will be created using the job’s label and logger_config.

configure(config)[source]#

Configure a stepped job instance, checking its step overrides (config.steps): each key must name one of the job’s steps, and each override must be a dict of options of that step’s configuration class. Values are checked when the step’s configuration is built, together with its defaults.

Parameters:

config (SteppedJobConfig) – Configuration of the job.

Raises:

  • TypeError – If config is not of the expected class, or a step’s override isn’t a dict.

  • ValueError – If an override names an unknown step, or an unknown option of a step.

Return type:

None

classmethod dependencies()[source]#

Names of the external programs that this job type needs: its own (_dependencies) and those of its steps, and of their steps, without building their configurations. The job checks them before its first step, on the compute site and in the shell that they set in the settings, or the defaults; a step whose configuration picks another site or shell checks them again when it starts.

Return type:

frozenset[str]
