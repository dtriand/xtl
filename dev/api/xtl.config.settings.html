xtl.config.settings module#

This module defines a set of Options Pydantic models that are used to configure various aspects of XTL. The main class that holds all settings is XTLSettings.

classmethod initialize(create=True)[source]#

Initialize from the first existing xtl.toml in locations(), in lookup order: XTL_CONFIG, local, user and global. Once loaded, the problems found by check() are logged as warnings.

If no file exists and create is True, the default settings are written to the first creatable location that succeeds (XTL_CONFIG, user, global; never local), logging a warning for each one that fails. If all of them fail, or create is False, the default settings are used in-memory.

This method never raises: a file that cannot be read is logged as an error and the default settings are used instead.

Parameters:

create (bool) – Whether to create a config file if none is found

Returns:

An instance of XTLSettings

Return type:

XTLSettings
