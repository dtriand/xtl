check_dependencies(dependencies, shell)[source]#

Check that dependencies can be found in a shell: for each dependency, a short script in the shell sets up the common settings and the dependency’s own (see prepare_setup()), then looks up every executable that the dependency provides. A dependency is found only if all of them are; a module that doesn’t load is reported too. Each dependency is checked on its own, and the outcome is remembered in its settings, so that it isn’t checked again on this site and in this shell until its settings change.

Parameters:

  • dependencies (Iterable[DependencySettings | str] | DependencySettings | str | None) – Dependency names or settings, or None.

  • shell (ShellType) – The shell to check in.

Returns:

One check per dependency, in the given order.

Return type:

list[DependencyCheck]

prepare_preamble(dependencies, shell, **kwargs)[source]#

The preamble of a batch file: the shebang, the site’s directives (if any), the setup of the dependencies (see prepare_setup()), and a guard line for each executable they provide, which ends the batch file with exit code 127 if the executable isn’t found, before any command runs. Then passed through the policy, if any.

Parameters:

  • dependencies (Iterable[DependencySettings | str] | DependencySettings | str | None) – Dependency names or settings, or None.

  • shell (ShellType) – The shell to write the preamble for.

  • kwargs – Passed to the site’s directives, e.g. config on a Slurm site.

Raises:

ValueError – If a name or a directory can’t be written safely in the shell.

Return type:

str

prepare_setup(dependencies, shell)[source]#

The lines that set up dependencies in a shell, each ending with the shell’s line ending: on this site, the common path and then each dependency’s are put first on PATH (so a dependency’s directory comes first).

Parameters:

  • shell (ShellType) – The shell to write the lines for.
