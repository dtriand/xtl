classmethod from_csv(s, *, delimiter=',', header_line=None, header_char='', formats=None, encoding='utf-8')[source]#

Create a Table from a CSV file or string. Quoted values are read as in csv; all values are strings.

A Path is a file. A string is the CSV content if it has a line break, otherwise a file if one of that name exists, else the CSV content.

Parameters:

  • s (str | Path) – Path to CSV file or CSV string content

  • delimiter (str) – Delimiter used in the CSV, one character (default: ‘,’)

  • header_line (int | None) – Line that contains headers (default: None); the lines before it are skipped

  • header_char (str) – Character that might prefix the header line (e.g., ‘#’)

  • formats (dict[str | int, str] | None) – Column formats used when rendering the table

  • encoding (str) – Encoding of the file.

Returns:

A new Table instance

to_csv(filename=None, delimiter=',', new_line='\n', header_char='', overwrite=False, keep_file_ext=False, formatted=True, encoding='utf-8')[source]#

Write the table to a CSV file. If filename is not provided, then the CSV will be returned as a string. Values with the delimiter, quotes or line breaks are quoted, as in csv.

Parameters:

  • filename (str | Path | None) – Optional output path for the CSV file.

  • delimiter (str) – Delimiter to use in the CSV, one character.

  • new_line (str) – Newline character to use in the CSV.

  • header_char (str) – Character to prepend to the header line (e.g., ‘#’).

  • overwrite (bool) – Overwrite the file if it already exists.

  • keep_file_ext (bool) – Keep the file extension if filename is provided.

  • formatted (bool) – Apply the column formats to the values (without padding).

  • encoding (str) – Encoding of the file.

Returns:

Either the CSV string or the output path.

Raises:

FileExistsError – If the file already exists and overwrite is False

Return type:

str | Path
