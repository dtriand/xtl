# xtl-core

The foundations of [xtl](https://github.com/dtriand/xtl) that don't need the scientific stack: validated options
(pydantic models with TOML/JSON I/O and versioned layouts), tables, file permissions, environment variables and
version information. It can be used without `xtl`.

```shell
pip install xtl-core
pip install "xtl-core[extra]"  # Table conversions to numpy, pandas and rich
```

Documentation: [dtriand.github.io/xtl/core](https://dtriand.github.io/xtl/core/index.html)
